GX Files

File manager & binary editor for iPhone. Free and open source.

Download IPA Source on GitHub

Install

Add this source to Feather, SideStore or AltStore — updates arrive automatically:

https://raw.githubusercontent.com/GRAFXXX/GX-Files/main/source/apps.json

Or download GXFiles.ipa from Releases and install it any way you like, including TrollStore and LiveContainer.

Installed viaWhat you can access
Feather / SideStore / AltStore“My files” (also in Files → On My iPhone → GX Files), linked folders, files shared into the app
LiveContainerAll of the above + LiveContainer’s shared folder, guest app data, tweaks
TrollStore / jailbreakThe whole file system

Features

  • Files — dual panels, favorites, search by name and content, duplicates, storage analysis, find & replace across folders (even inside ZIP/APK/IPA), Wi‑Fi transfer.
  • Formats — edit ZIP/APK/IPA/JAR in place; tar, 7z, rar; text and hex editors; plist, JSON, .strings; SQLite console; APK v1 + v2 signing; IPA name, icon and Info.plist.
  • Binary editor — Mach-O and ELF strings, Objective-C headers, ARM64 disassembler and assembler, approximate C pseudocode, embedded images and fonts, ad-hoc re-signing.
  • Compiler on iPhone — built-in TinyCC with iOS SDK headers: write C, get an arm64 dylib.
  • 8 languages — English, Русский, Українська, Беларуская, Deutsch, Français, Español, Português.

Responsible use

The binary editor and compiler are for studying, debugging and modifying your own apps and apps you have the right to modify. Please don’t use GX Files to violate licenses, bypass protections, or cheat in online games.
